连接配置

推荐结构体配置，避免驱动和 DSN 参数顺序写错。

数据库差异

覆盖 PostgreSQL / MySQL / SQLite 的 DSN 差异与占位符语义差异。

高级能力

Hooks、读写分离、多数据源等高级特性明确开启，不默认启用。

快速开始

  • 按结构体传入配置：orm.Open(orm.Config{...})
  • 只在显式配置后启用扩展功能
  • 使用 WithPrefix / WithLogger / WithHooks 等链式组合方式
  • 默认行为保持单库、简洁和可预测
