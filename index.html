gobreath-orm

一个面向 Go 工程的极简 ORM。用结构体配置连接，显式开启高级能力，保持默认行为简单、可控、易维护。

GitHub 查看特性
Config 结构体配置入口
Opt-in 高级能力显式开启
Go 现代 Go 生态
db, err := orm.Open(orm.Config{ Driver: "mysql", DSN: "user:pass@tcp(localhost:3306)/demo", })

清晰连接配置

推荐结构体参数写法，避免 Driver / DSN 位置写错，适用于 MySQL / PostgreSQL / SQLite。

显式功能门控

Hooks、读写分离、多数据源等能力只有在配置开启时才生效，默认行为保持简单透明。

工程友好

适合从小型项目走向中大型服务，默认不引入隐式魔法行为，便于维护和审计。
